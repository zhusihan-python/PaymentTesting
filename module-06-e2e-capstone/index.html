在终端进入 module-06-e2e-capstone 目录，执行以下命令即可一键跑通全部 5 个核心端到端用例：

# 1. 安装 pytest（如本地尚未安装）
pip install pytest

# 2. 运行端到端测试套件
cd module-06-e2e-capstone
pytest -v

Module 3：ISO 8583 协议与 Mock 挡板实战

ISO 8583 不是 JSON，而是一种极度紧凑的定长/变长报文。掌握 MTI + Bitmap + 数据元，就能看懂任意银行卡报文。

1. 一笔 ISO 8583 报文的三段式结构

1. MTI（4 位数字）定义报文类型：如 0100 授权请求、0110 授权响应、0420 冲正。
2. Bitmap（64 位 / 16 字节 Hex）二进制开关阵列：第 N 位为 1 表示携带了 Field N；为 0 则省略。
3. Data Elements（数据元）按位图开启的顺序依次拼接实际业务值（如卡号、金额、响应码）。

2. 发卡行测试最高频的 6 个核心数据元
